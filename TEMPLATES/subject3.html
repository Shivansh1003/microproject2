UNIT 1 • NOTES READY

Binary values and logic gates

Digital logic uses two values: 0 (false) and 1 (true).

AND, OR, and NOT

An AND gate gives 1 only when every input is 1. An OR gate gives 1 when at least one input is 1. A NOT gate reverses its input.

Truth tables

A truth table lists every possible input combination and the corresponding output for a logic circuit.

Other basic gates

  • NAND: opposite of AND; it outputs 0 only when every input is 1.
  • NOR: opposite of OR; it outputs 1 only when every input is 0.
  • XOR: outputs 1 when the inputs are different.
  • XNOR: outputs 1 when the inputs are the same.

Number systems

Binary uses base 2, decimal uses base 10, and hexadecimal uses base 16. Hexadecimal represents binary values in a shorter form.

Example: the 8-bit binary value 11111111 is 255 in decimal and FF in hexadecimal.

Combinational and sequential logic

Combinational outputs depend only on current inputs. Sequential outputs can also depend on stored previous states.

Design steps

  1. Define required inputs and outputs.
  2. Write a truth table for the behavior.
  3. Simplify the Boolean expressions.
  4. Draw and test the circuit.
