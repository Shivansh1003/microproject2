Digital Logic Design

Binary values

Digital logic uses two values: 0 (false) and 1 (true).

AND gate

An AND gate gives 1 only when both inputs are 1. For inputs 1 and 0, the output is 0.

More notes

An OR gate gives 1 when at least one input is 1. A NOT gate reverses its input, changing 0 to 1 and 1 to 0.

A truth table lists every possible input combination and the output for a logic circuit. It is a useful way to check whether a circuit behaves as intended.

Other basic gates

  • NAND: the opposite of AND. It outputs 0 only when every input is 1.
  • NOR: the opposite of OR. It outputs 1 only when every input is 0.
  • XOR: outputs 1 when the inputs are different.
  • XNOR: outputs 1 when the inputs are the same.

Number systems

Binary uses base 2, decimal uses base 10, and hexadecimal uses base 16. Hexadecimal is often used to represent binary values in a shorter form.

Example: the 8-bit binary value 11111111 is 255 in decimal and FF in hexadecimal.

Combinational logic

The output of combinational logic depends only on the current inputs. Examples include adders, multiplexers, decoders, and encoders.

Sequential logic

Sequential circuits use memory elements such as flip-flops and latches. Their output can depend on current inputs and previous states.

Design steps

  1. Define the required inputs and outputs.
  2. Write a truth table for the behavior.
  3. Simplify the Boolean expressions.
  4. Draw and test the circuit.
