UNIT 1 • NOTES READY

Internet and the web

The internet connects computers. The web lets browsers request pages and resources from web servers.

Web basics

HTML structures a page, CSS styles it, and JavaScript adds interactive behavior.

How a page loads

  1. The browser finds the server through a domain name.
  2. The browser sends an HTTP or HTTPS request.
  3. The server returns HTML and related resources.
  4. The browser requests stylesheets, images, scripts, and other files.
  5. The browser builds and displays the page.

URLs and HTTP methods

A URL identifies a resource and commonly includes a protocol, domain name, and path.

  • GET: requests a resource.
  • POST: submits data to the server.
  • PUT: creates or replaces a resource.
  • DELETE: removes a resource.

HTML basics

HTML uses elements and tags to describe content. Semantic elements such as <header>, <main>, <section>, and <footer> describe page structure.

CSS basics

CSS uses selectors and declarations to control presentation. The box model includes content, padding, border, and margin.

Responsive design and security

Flexible widths, grid layouts, and media queries help pages adapt to phones, tablets, and desktops. HTTPS encrypts browser-server communication.
