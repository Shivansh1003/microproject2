Internet & Web Technology

Internet and the web

The internet connects computers. The web lets browsers request pages from web servers.

Web basics

HTML structures a page, CSS styles it, and JavaScript can add interactive behavior.

More notes

A browser sends an HTTP request when it needs a web resource. A web server responds with the requested page or other data.

A URL identifies a resource on the web. It commonly includes a protocol, a domain name, and an optional path to a specific page.

How a page loads

  1. The browser finds the server through a domain name.
  2. The browser sends an HTTP or HTTPS request.
  3. The server returns HTML and related resources.
  4. The browser requests stylesheets, images, scripts, and other files.
  5. The browser builds and displays the page.

Common HTTP methods

  • GET: requests a resource.
  • POST: submits data to the server.
  • PUT: replaces or creates a resource.
  • DELETE: removes a resource.

HTML basics

HTML uses elements and tags to describe content. Semantic elements such as <header>, <main>, <section>, and <footer> describe the purpose of page sections.

CSS basics

CSS uses selectors to choose HTML elements and declarations to set their appearance. The box model includes content, padding, border, and margin.

Responsive design

Responsive pages work across screen sizes. Flexible widths, grid layouts, and media queries help adapt content for phones, tablets, and desktops.

Security reminder

HTTPS encrypts communication between the browser and server. Applications should validate input, protect passwords, and avoid exposing sensitive information.
