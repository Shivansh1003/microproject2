UNIT 1 • NOTES READY

Matrices, rank, and echelon forms

A matrix organizes numbers into rows and columns. Row operations help simplify a matrix without changing the key information needed to solve systems of linear equations.

1. What is a matrix?

A matrix is a rectangular arrangement of entries. A matrix with m rows and n columns has order m × n.

Example: a matrix of order 2 × 3 A = [ 1 2 3 ]
    [ 4 5 6 ]
  • A matrix is square when it has the same number of rows and columns.
  • A zero matrix has only zero entries.
  • An identity matrix has 1s on its main diagonal and 0s elsewhere.

2. Elementary row operations

These operations transform a matrix into a simpler form:

  1. Interchange two rows: Ri ↔ Rj.
  2. Multiply a row by a nonzero constant: Ri → kRi, where k ≠ 0.
  3. Add a multiple of one row to another: Ri → Ri + kRj.

These are called elementary row operations. They preserve the rank of a matrix and the solution set of the corresponding system when applied to its augmented matrix.

3. Row echelon form

A matrix is in row echelon form (REF) when:

  • Any rows containing only zeros are at the bottom.
  • The first nonzero entry in each nonzero row (its leading entry or pivot) is to the right of the pivot in the row above.
  • All entries below each pivot are zero.

In reduced row echelon form (RREF), every pivot is 1 and is the only nonzero entry in its column.

4. Worked example: find the rank

Use row operations to reduce the following matrix to echelon form:

Starting matrix A = [ 1 2 1 ]
    [ 2 4 0 ]
    [ 3 6 3 ]
  1. Apply R2 → R2 - 2R1 and R3 → R3 - 3R1.
  2. Scale the second row with R2 → -½R2.
Row echelon form [ 1 2 1 ]
[ 0 0 1 ]
[ 0 0 0 ]

There are two nonzero rows and two pivots, so rank(A) = 2. The pivot columns are columns 1 and 3.

Reduced row echelon form [ 1 2 0 ]
[ 0 0 1 ]
[ 0 0 0 ]

5. Rank of a matrix

The rank is the number of pivot positions in an echelon form. It is also the maximum number of linearly independent rows or columns.

Quick check Reduce the matrix to REF, count its nonzero rows (or pivots), and that count is its rank.
  • The rank cannot be greater than the number of rows or columns.
  • A zero matrix has rank 0.
  • For a square matrix, full rank means its rows and columns are independent.
