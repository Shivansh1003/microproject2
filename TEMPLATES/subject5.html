UNIT 1 • NOTES READY

Basic idea

Programming means writing instructions for a computer. Variables store values that a program can use.

Variables and data types

Common types include integers, floating-point numbers, strings, booleans, lists, and dictionaries.

Conditions

A condition can check whether a number is greater than zero and report that it is positive. Comparison operators include ==, !=, <, <=, >, and >=.

Loops

Loops repeat a set of instructions. In Python, for number in range(5): repeats with the values 0, 1, 2, 3, and 4.

Functions

Functions group reusable instructions under a name. They can accept input values and return a result.

def add(a, b):
    return a + b

result = add(3, 4)

This function accepts two values, adds them, and returns 7.

Data structures

  • List: an ordered collection that can change.
  • Tuple: an ordered collection that normally cannot change.
  • Dictionary: stores values using unique keys.
  • Set: stores a collection of unique values.

Debugging tips

  1. Read the error and identify the file and line number.
  2. Check variable values before and after the failing operation.
  3. Divide the problem into smaller parts and test each part.
  4. Use descriptive names and log or print information when needed.
