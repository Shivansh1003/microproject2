Programming

Basic idea

Programming means writing instructions for a computer. Variables store values that a program can use.

Example

A condition can check whether a number is greater than zero and report that it is positive.

More notes

Loops repeat a set of instructions. A loop can process each item in a list or continue while a condition remains true.

Functions group instructions under a name so they can be reused. They can accept input values and return a result to the rest of a program.

Variables and data types

Variables have names and store values. Common types include integers, floating-point numbers, strings, booleans, lists, and dictionaries.

Example loop

In Python, for number in range(5): repeats its indented block with the values 0, 1, 2, 3, and 4.

Example function

def add(a, b):
    return a + b

result = add(3, 4)

This function accepts two values, adds them, and returns the result 7.

Conditions

A condition can use operators such as ==, !=, <, <=, >, and >=. Logical operators include and, or, and not.

Data structures

  • List: an ordered collection that can change.
  • Tuple: an ordered collection that normally cannot change.
  • Dictionary: stores values using unique keys.
  • Set: stores a collection of unique values.

Debugging tips

  1. Read the error message and identify the file and line number.
  2. Check variable values before and after the failing operation.
  3. Divide the problem into smaller parts and test each part.
  4. Use descriptive variable names and print or log information when needed.
