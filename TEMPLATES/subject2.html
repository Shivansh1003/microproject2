Machine Learning

What is machine learning?

Machine learning helps computers find patterns in examples and use them to make predictions.

Example

A computer can learn from pictures labeled “cat” or “dog” and use what it learned to classify a new picture.

More notes

Training data is used to teach a model, while test data helps check how well it works on examples it has not seen before.

In supervised learning, examples include correct answers called labels. A model compares its predictions with those labels and adjusts to reduce errors.

Types of learning

  • Supervised learning: uses labeled data for classification or regression.
  • Unsupervised learning: finds patterns or groups in data without labels.
  • Reinforcement learning: learns by receiving rewards or penalties from an environment.

Common tasks

Classification predicts a category, such as spam or not spam. Regression predicts a continuous number, such as a house price.

Overfitting and underfitting

Overfitting happens when a model learns the training data too closely and performs poorly on new data. Underfitting happens when a model is too simple to learn the main patterns.

Model workflow

  1. Collect and clean the data.
  2. Separate the data into training, validation, and test sets.
  3. Choose a model and fit it with the training data.
  4. Tune the model using the validation data.
  5. Measure final performance with test data.

Important terms

  • Feature: an input used to make a prediction.
  • Label: the known result in supervised learning.
  • Accuracy: the fraction of predictions that are correct.
  • Loss: a measure of how far predictions are from the expected answers.
